# User Stories

Project: CampusQR

Version: 1.0

---

# Visitor

## US-001

As a visitor,

I want to scan a QR code,

So that I can access the digital campus.

Priority: High

---

## US-002

As a visitor,

I want to search for a building,

So that I can easily find it.

Priority: High

---

## US-003

As a visitor,

I want to view the shortest route,

So that I can reach my destination quickly.

Priority: High

---

## US-004

As a visitor,

I want to view information about a building,

So that I know what services are available there.

Priority: High

---

## US-005

As a visitor,

I want to access emergency contacts,

So that I can get help when needed.

Priority: Medium

---

# Student

## US-006

As a student,

I want to quickly navigate to different departments,

So that I can save time between classes.

Priority: High

---

## US-007

As a student,

I want to locate campus facilities,

So that I can easily access them.

Priority: Medium

---

# Administrator

## US-008

As an administrator,

I want to add new buildings,

So that the campus information remains updated.

Priority: High

---

## US-009

As an administrator,

I want to update building information,

So that users always receive accurate information.

Priority: High

---

## US-010

As an administrator,

I want to generate QR codes,

So that users can access the platform from different campus locations.

Priority: High
